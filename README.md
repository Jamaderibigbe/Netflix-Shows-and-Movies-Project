## 🎯 Business Problem

Netflix offers one of the world's largest streaming libraries, containing thousands of movies and TV shows. Analyzing such a large volume of content manually is inefficient and makes it difficult to uncover meaningful insights that support strategic decision-making.

This project analyzes a Netflix dataset containing over **82,000 records** to identify trends in content distribution, genre popularity, release patterns, content ratings, and geographic availability. The goal is to transform raw data into actionable insights through interactive reporting and visualization.

---

## 💡 Solution

To solve this problem, I developed an end-to-end data analytics solution using **SQL** and **Power BI**.

The project involved:

- Cleaning and transforming raw data.
- Performing exploratory data analysis (EDA).
- Writing SQL queries to extract meaningful business insights.
- Building an interactive Power BI dashboard for data visualization.
- Creating key performance indicators (KPIs) to support business reporting.

The dashboard enables users to:

- 📺 Compare the distribution of **Movies** and **TV Shows**
- 🌍 Analyze content by **Country**
- 🎭 Explore the most popular **Genres**
- 📅 Identify content release trends over time
- ⭐ Analyze content ratings and maturity classifications
- 🔍 Filter and interact with the data for deeper analysis

By converting raw data into interactive visualizations, this project demonstrates how data analytics can support informed business decisions and improve understanding of Netflix's content library.
